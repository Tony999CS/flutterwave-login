# Flutterwave Login Demo

A simple Flutter login UI. The login action is a front-end demo only; connect a trusted authentication backend before using it with real accounts.

## Run locally
```bash
flutter pub get
flutter run -d chrome
```

## Build for web
```bash
flutter build web
```

Upload this project to GitHub. For a hosted website, deploy the generated `build/web` directory with GitHub Pages or another static host.
